ft_irc

Serveur IRC conforme à la RFC 1459. Il accepte plusieurs clients en même temps grâce à des sockets TCP non bloquants et au multiplexage d'entrées/sorties avec epoll. Il gère les canaux et leurs commandes (JOIN, KICK, INVITE, TOPIC, MODE), fonctionne avec le client Irssi ou Netcat, et embarque un bot qui répond aux questions sur les dinosaures.

IRC server compliant with RFC 1459. It handles several clients at once using non-blocking TCP sockets and I/O multiplexing with epoll. It supports channels and their commands (JOIN, KICK, INVITE, TOPIC, MODE), works with the Irssi client or Netcat, and includes a bot that answers questions about dinosaurs.

MiniRT

Mini ray tracer. Le programme lit une scène décrite dans un fichier .rt (caméra, lumières, sphères, plans, cylindres), lance un rayon par pixel pour trouver l'objet le plus proche, puis calcule l'éclairage ambiant, la lumière ponctuelle et les ombres portées. L'image est affichée avec la MiniLibX.

A small ray tracer. The program reads a scene described in a .rt file (camera, lights, spheres, planes, cylinders), casts one ray per pixel to find the closest object, then computes ambient light, point light and cast shadows. The image is displayed with the MiniLibX.

Minishell

Shell Unix simplifié, inspiré de bash. La saisie est lue avec readline, découpée en tokens, puis les variables d'environnement sont développées en respectant les quotes. Les commandes s'exécutent avec pipes, redirections et heredocs. Les builtins (echo, cd, pwd, export, unset, env, exit) et les signaux Ctrl-C, Ctrl-D et Ctrl-\ sont gérés.

A simplified Unix shell inspired by bash. Input is read with readline and split into tokens, then environment variables are expanded while respecting quotes. Commands run with pipes, redirections and heredocs. Builtins (echo, cd, pwd, export, unset, env, exit) and the Ctrl-C, Ctrl-D and Ctrl-\ signals are handled.

FdF

Visualiseur de relief en fil de fer. Le programme lit une carte où chaque nombre est une altitude, puis la projette en vue isométrique avec la MiniLibX. Au clavier, on peut zoomer, déplacer la carte et accentuer ou aplatir le relief.

A wireframe terrain viewer. The program reads a map where each number is an altitude and projects it in isometric view with the MiniLibX. With the keyboard you can zoom, move the map and raise or flatten the terrain.
